# AutoBot 使用文档

面向 sitin PWA 的自动化测试工具。一端是**管理控制台**(网页,负责下发用例、看结果),一端是**设备端 Agent**(注入到被测网页里,负责实际执行 / 录制)。两端通过 Firebase 实时同步,设备无需插件、无需安装。

- 控制台地址:`https://presence-io.github.io/sitin-pwa-automation/dashboard.html`
- 设备端脚本:`https://presence-io.github.io/sitin-pwa-automation/autobot.js`

---

## 一、整体概念

| 角色 | 是什么 | 在哪里跑 |
|------|--------|----------|
| **控制台 (Console)** | 一个网页面板,管理设备、用例、执行、结果 | 任意浏览器打开上面的 dashboard 地址 |
| **设备端 (Agent)** | 一段注入被测页面的脚本 `autobot.js` | 手机 / 电脑上被测的那个网页里 |
| **Firebase** | 中间的实时数据库,双向同步命令与结果 | 云端,自动,无需关心 |

一句话流程:**控制台勾选设备 + 用例 → 下发 → 设备端执行 → 结果实时回传控制台**。

## 二、管理端(控制台)

### 2.1 界面布局

打开控制台后是三块布局:

- **顶栏** — 左侧是产品名;右侧是「选择项目」下拉、「添加设备」、「使用指南」。**用之前先在这里选好项目**,用例列表按项目加载。
- **左侧栏** — 上半是「设备」列表(带在线数),下半是「测试用例」列表。
- **右侧主区** — 顶部是「运行条」(三步引导 + 运行按钮),下面依次是「阶段任务」「执行结果」「历史」。

### 2.2 三步跑通一次测试

运行条上明确写着三步,照着做即可:

1. **勾选设备** — 在左侧「设备」里勾选一台或多台(可多选,并行执行)。
2. **选测试用例** — 在左侧「测试用例」里点选一条用例。
3. **运行** — 点右上角绿色 **▶ 运行选中用例**。按钮会显示将在几台设备上运行。

结果会实时出现在右侧「执行结果」区。

### 2.3 设备管理

- 在线设备是**绿色圆点**,离线是**红色**。
- 点设备卡片上的**眼睛图标** → 打开设备检查器:实时屏幕镜像(WebRTC)、操作回放(rrweb)、日志、网络、存储。
- 点**垃圾桶图标**删除设备记录。
- 设备接入方式见下方「三、设备端」。

### 2.4 测试用例

用例来源有三类,列表里用标记区分:

- **远程用例** — 从 GitHub Pages 加载,**只读**。
- **带「云」标记** — Agent 或控制台上传的,**可编辑 / 删除**。
- **设备录制(REC 标记)** — 在设备端录制后同步上来的操作流程。

常用操作:

- **预览** — 点用例查看 / 编辑 JSON,改完 **Save** 保存。
- **导入 / 粘贴 JSON** — 从文件或剪贴板导入用例。

### 2.5 AI 生成用例

不想手写 JSON 时:

1. 用自然语言描述测试场景。
2. 点 **Generate Prompt** — 自动带上当前项目配置和用例格式规范。
3. 复制到 Claude / ChatGPT → 把生成的 JSON 粘回来 → 导入。

### 2.6 阶段任务(Stages)

预设的 **Stage 1–5**,覆盖「注册 → 提现」完整生命周期:

- 点单个 **▶** 执行某一阶段;点 **顺序执行 S1→S5** 跑完整链路(会注销账号并从头开始,有二次确认)。
- 每台设备的进度实时更新(圆点 + 中文状态:运行中 / 完成 / 失败)。
- 阶段流程本身就是可编辑 JSON,在预览里改。

### 2.7 结果与历史

- **执行结果** — 实时,刷新页面自动恢复。
- **历史** — 所有历史命令,每条都有 **报告** 按钮。
- **报告** — 通过率、逐步结果、失败截图、埋点事件及完整参数。
- 可单条删除或清空全部。

## 三、设备端(Agent)

设备端 = 把 `autobot.js` 注入到**被测网页**里。无需安装 App、无需插件,手机电脑通用。

### 3.1 接入一台设备(临时,最常用)

在被测网页的 **DevTools Console** 里粘贴并回车:

```js
fetch('https://presence-io.github.io/sitin-pwa-automation/autobot.js')
  .then(r=>r.text())
  .then(t=>{const s=document.createElement('script');s.textContent=t;document.body.appendChild(s)})
```

> 控制台「添加设备」弹窗里点代码块即可复制。几秒内这台设备就会出现在控制台的设备列表中。

手机上没有 Console?两种办法:iOS 用 Safari 连 Mac 的「Web 检查器」;Android 用 Chrome 的 `chrome://inspect` 远程调试;或用下面的「永久注入」。

### 3.2 永久注入(免每次粘贴)

在被测页面里加一段 script(通常由开发在测试环境注入),受本地开关控制:

```html
<script>
if (localStorage.getItem('autobot_enabled') === '1') {
  var s = document.createElement('script');
  s.src = 'https://presence-io.github.io/sitin-pwa-automation/autobot.js';
  s.dataset.project = 'your-project';
  document.body.appendChild(s);
}
</script>
```

需要时在该设备执行 `localStorage.setItem('autobot_enabled','1')` 并刷新即可自动接入;`data-project` 指定项目。

### 3.3 在设备上录制操作(生成用例)

注入后页面会出现 AutoBot 面板:

1. 打开面板 → **教学模式** → **开始录制**。
2. 正常操作页面 — 点击、输入、滚动、导航**全部自动捕获**(连续输入自动合并,滚动 300ms 防抖)。
3. 点列表项时会弹**文本选择器**,选一个稳定的文本用于日后匹配。
4. 需要校验时点 minibar 上的 **[+断言]**,插入断言(URL / 文案 / 埋点事件)。
5. **停止录制 → 保存 → 转为用例**,自动生成测试用例。
6. 录制和转换出的用例**自动同步到 Firebase**,控制台里立刻可见(带 REC / 云 标记)。

### 3.4 内置可调用函数(call)

用例里可用 `call` 直接调用设备端封装好的业务动作:

| 函数 | 参数 | 说明 |
|------|------|------|
| `deleteAccount` | — | 注销当前账号(走 /debug 页) |
| `quickLogin` | — | 快速登录 |
| `onboarding` | — | 自动完成注册流程 |
| `cashout` | — | 触发提现 + 自动关弹窗 |
| `completeTask` | `[taskId, label]` | 通过 Debug 页完成指定任务 |
| `mockCallsAuto` | `[收益$, 时长min]` | 自动算出所需 Mock Call 次数 |
| `mockCalls` | `[count]` | 执行指定次数 Mock Call |
| `clearLocalStorage` | — | 清 localStorage(保留 autobot 配置) |
| `clearAll` | — | 清除所有浏览器存储 |

## 四、用例格式(参考)

```json
{
  "name": "登录验证",
  "cases": [{
    "name": "快速登录并检查埋点",
    "steps": [
      { "action": "navigate", "url": "/login" },
      { "action": "click", "locators": [{"type":"text","value":"Quick Login"}], "tag": "button" },
      { "action": "assert", "assertType": "url", "expected": "/home" },
      { "action": "assert", "assertType": "eventFired", "sdk": "rangers", "event": "login_success" }
    ]
  }]
}
```

### 支持的操作类型

| 操作 | 说明 | 录制方式 |
|------|------|----------|
| `click` | 点击元素 | 自动捕获 |
| `input` | 输入文字 | 自动捕获(连续输入合并) |
| `scroll` | 页面滚动 | 自动捕获(300ms 防抖) |
| `navigate` | 页面跳转 | 自动捕获(SPA 路由) |
| `select` | 下拉选择 | 自动捕获 |
| `assert` | 插入断言 | 手动(minibar [+断言]) |
| `wait` | 等待 N 毫秒 | 手写 JSON |
| `call` | 调用内置函数 | 手写 JSON |

## 五、常见问题

- **设备没出现在列表里?** 确认注入脚本已成功执行(Console 无报错)、网络能访问 Firebase、被测页仍打开着。
- **用例改不了?** 「远程用例」是只读的;要改就复制成「云」用例或重新导入。
- **手机上录不了 / 看不到面板?** 确认注入成功;iOS 走 Safari Web 检查器,Android 走 chrome://inspect,或用永久注入方式。
- **跑 Stage 会清数据吗?** 顺序执行 S1→S5 会注销账号并从头开始,执行前有二次确认。
